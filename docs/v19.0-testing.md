# Domain Controller v19.0 testing

## Scope and source

The appliance uses Samba, Kerberos, CUPS, Lighttpd, and supporting packages
from signed Debian Trixie and TurnKey v19 APT repositories. Samba is the
identity-defining application; its practical updater is signed APT metadata
plus a non-mutating upgrade simulation.

The v19 migration is based on frozen candidate
`ecc3ab330697175ff5115ed3f465ca3bc6ddf9cf`. Product loop 1 removes the
administrator password from both OS process-argument boundaries and from
console and failure-log command retention. Firstboot sends the password on
stdin. Provisioning calls Samba's public Python entry point in-process and
redacts reflected output before it can reach logs.

Inherited Core v19 checks cover normal init, multi-user target, SSH, cron,
Trixie identity, common firstboot fencing, and baseline Webmin behavior. This
appliance's own test covers its modified firstboot, identity, DNS, Kerberos,
Samba, CUPS default, service restart, authenticated data path, join path, and
updater boundary.

## Commands

Cheap gates:

```sh
bash -n tests/v19.sh overlay/usr/lib/inithooks/firstboot.d/40domain-controller
python3 tests/password-handoff.py
git diff --check
```

Exact acceptance uses the shared serialized harness:

```sh
TKL_HARNESS_LOCK_FILE=/home/agent/.local/state/non-liraz-v19-release-qa/build.lock \
TKL_HARNESS_STATE_DIR=/home/agent/.local/state/non-liraz-v19-release-qa/domain-controller \
/home/agent/turnkey/tools/test-v19-appliance domain-controller \
    --source /home/agent/.local/state/non-liraz-v19-release-qa/worktrees/domain-controller/candidate
```

## Evidence and limitations

Exact run identity, source and harness archive hashes, configured-root mode,
installed Samba version, updater result, retained logs, cleanup, and final
verdict will be recorded here after the clean committed acceptance run.

The Docker gate does not exercise installer, kernel, physical printer, or a
Windows desktop. The local authenticated SMB round trip, Kerberos ticket, DNS
query, and disposable Samba DC join exercise the appliance side without an
external Windows fixture.
